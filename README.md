# Серверная программа vcalc

Курсовая работа по дисциплине «Технологии и методы программирования».
Тема: «Программная реализация сетевого сервера».

## Описание
Серверная программа на C++17, реализующая клиент-серверное взаимодействие по протоколу TCP.
Программа обеспечивает:
*   Аутентификацию клиентов с использованием хэш-функции **MD5** и динамической «соли» (SALT16), генерируемой сервером.
*   Приём числовых векторов (тип `double`) в двоичном формате.
*   Вычисление **суммы квадратов** элементов каждого вектора.
*   Отправку результатов обратно клиенту в двоичном формате.
*   Ведение журнала событий и ошибок с указанием даты, времени и уровня критичности.
*   Разбор параметров командной строки (с использованием библиотеки Boost).
*   Документирование кода с помощью Doxygen.

## Требования
Для сборки и работы программы необходимы:
*   Компилятор с поддержкой C++17 (`g++`).
*   Библиотека **Crypto++** (для MD5 и генерации соли).
*   Библиотека **Boost** (модуль `program_options`).
*   Утилита **CMake** или **Make**.
*   (Опционально) **Doxygen** для генерации документации.
