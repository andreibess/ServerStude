# Серверная программа vcalc

Курсовая работа по дисциплине «Технологии и методы программирования».
Тема: «Программная реализация сетевого сервера».

## Описание
Серверная программа на C++17, реализующая клиент-серверное взаимодействие по протоколу TCP.
Программа обеспечивает:
*   Аутентификацию клиентов с использованием хэш-функции **MD5** и динамической «соли» (SALT16), генерируемой сервером.
*   Приём числовых векторов (тип `double`) в двоичном формате.
*   Вычисление **суммы квадратов** элементов каждого вектора.
*   Отправку результатов обратно клиенту в двоичном формате.
*   Ведение журнала событий и ошибок с указанием даты, времени и уровня критичности.
*   Разбор параметров командной строки (с использованием библиотеки Boost).
*   Документирование кода с помощью Doxygen.

## Требования
Для сборки и работы программы необходимы:
*   Компилятор с поддержкой C++17 (`g++`).
*   Библиотека **Crypto++** (для MD5 и генерации соли).
*   Библиотека **Boost** (модуль `program_options`).
*   Утилита **Make** для сборки.
*   (Опционально) **Doxygen** для генерации документации.

Установка зависимостей в Debian/Ubuntu:
sudo apt update
sudo apt install g++ make libcrypto++-dev libboost-program-options-dev doxygen

## Сборка
В корне проекта выполните:
make rebuild
После успешной сборки исполняемый файл сервера появится по пути bin/server.

## Запуск
1. Подготовка базы данных
Убедитесь, что в файле data/db.txt есть пользователь, которого будет использовать клиент (по умолчанию user с паролем P@ssW0rd):
echo "user:P@ssW0rd" > data/db.txt

2. Запуск сервера
Запустите сервер из корневой директории проекта, указав пути к базе данных и журналу:
./bin/server -d data/db.txt -l logs/vcalc.log
Параметры командной строки:
- -d (или --db) — путь к файлу базы клиентов (по умолчанию /etc/vcalc.conf).
- -l (или --log) — путь к файлу журнала (по умолчанию /var/log/vcalc.log).
- -p (или --port) — порт для прослушивания (по умолчанию 33333).
- -h (или --help) — вывод справки.

Сервер перейдет в режим ожидания подключений. В лог-файле появится запись Server started on port 33333.

3. Запуск клиента (для тестирования)
Откройте второй терминал (не закрывая сервер) и запустите тестовый клиент из папки dumb_client:
./dumb_client/client_double -H MD5 -S s
(Клиент всегда подключается к 127.0.0.1:33333 и использует логин user / пароль P@ssW0rd).
Если клиент выведет результаты вычислений (суммы квадратов) и вернется в командную строку — сервер работает корректно.

## Формат базы данных (db.txt)
База данных представляет собой текстовый файл, где каждая строка содержит пару «логин:пароль».
Пример:
user:P@ssW0rd
admin:secret123

## Документация
Для генерации HTML-документации выполните:
doxygen Doxyfile
Готовая документация будет доступна в папке html/index.html. Её можно открыть в любом браузере.

## Структура проекта
* include/ — заголовочные файлы (.h).
* src/ — исходный код (.cpp).
* bin/ — скомпилированный исполняемый файл (создается автоматически).
* obj/ — объектные файлы сборки (создается автоматически).
* data/ — файлы баз данных (db.txt).
* logs/ — файлы журналов.
* tests/ — модульные тесты (если реализованы).
* Doxyfile — конфигурация для Doxygen.
* Makefile — скрипт сборки.
